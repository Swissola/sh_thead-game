<objective>
Give the table's two card piles keyboard parity with the mouse: the face-up pile as a multi-selectable listbox, the face-down pile as a strictly single-select listbox (RESP-04, D-03).

Purpose: a same-rank multi-card play is just as common from the face-up pile as from the hand, so keyboard play is incomplete without it. Face-down cards are the opposite case — their rank is unknown until played, so a UI that let a keyboard user select two of them would imply a legality guarantee that does not exist. The two piles must therefore be two separate listboxes, not one.
Output: an accessible `Table.tsx` and the phase's dedicated table test file.
</objective>
