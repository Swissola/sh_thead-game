<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL path → app state | `/join/:code` is fully attacker-controllable by whoever sends the link |
| localStorage → menu inputs | Stored name is unvalidated persisted input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-35 | Tampering | Malicious `/join/<payload>` path | mitigate | The parsed segment only seeds a controlled React input, never touches `dangerouslySetInnerHTML` or a template, and is uppercased then sent as a JSON body value; a bad code simply returns `ROOM_NOT_FOUND` |
| T-02-36 | Tampering | Stored last-used name | mitigate | Rendered as a React text-input value, so it is escaped by React; server-side it is stored as a jsonb string and rendered the same way on every other client |
| T-02-37 | Spoofing | Rendering the app before identity resolves | mitigate | `GameProvider` children are gated on a resolved player id, so no move can be dispatched under an empty identity; the Edge Functions independently reject unauthenticated callers |
</threat_model>
