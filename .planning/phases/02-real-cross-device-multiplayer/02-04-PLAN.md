  <action>
Create `src/supabase/session.ts` exporting `ensurePlayerIdentity(): Promise<{ playerId: string | null; error?: string }>`.

It must check `getSupabaseClient().auth.getSession()` first and only call
`signInAnonymously()` when there is no session. Calling `signInAnonymously()` unconditionally
mints a brand-new anonymous user on every page load, which silently destroys D-01's
auto-rejoin guarantee and is the single most damaging mistake available here

(RESEARCH.md Pitfall 6) and burning that during development is easy.

storage, a different browser) is D-02's expected fallback path, not a crash. The caller in plan
02-10 renders the menu and lets the player rejoin manually by room code and name.

Export `resetIdentityMemoForTests()` clearing the memo, so tests can exercise each branch.
